# Ande: verifiering av OpenAI-koppling 2026-10-23

## Omfattning

Den publika bokföringsdemons läsande assistent ansluts till OpenAI via en
separat servernyckel. Ingen plattformsinloggning krävs. AI-anrop får bara den
explicit valda, begränsade demokontexten och har inga verktyg som ändrar
bokföring, skickar betalningar eller läser produktionsbolagens uppgifter.
Användaren har uttryckligen valt offentlig användning utan dygnsbudget.
Korta spamgränser och samtidighetsgränser finns kvar.

Kommandon från repots rot:

```sh
npm run build
node --test --test-concurrency=1 server/bokforing-ande*.test.mjs
node --test server/bokforing-demo-http.test.mjs
node --test --test-concurrency=1 server/pilot-http.test.mjs server/tenant-gateway.test.mjs
PLAYWRIGHT_CHROMIUM_EXECUTABLE=/usr/bin/chromium npx playwright test -c scripts/playwright-bokforing.config.mjs tests/bokforing-ande.spec.ts
PLAYWRIGHT_CHROMIUM_EXECUTABLE=/usr/bin/chromium npx playwright test -c scripts/playwright-bokforing.config.mjs tests/bokforing-suite.spec.ts tests/bokforing-wiki.spec.ts
```

Efter den gemensamma körningen ändrades instruktionen för att uttryckligen
ange öre/SEK och ofullständiga radurval; providerns samtliga 16 tester
kördes åter och godkändes. Testerna använder simulerad OpenAI-transport.
HTTP-provet använder en fiktiv nyckel och enbart förfrågningar som ska
avvisas före någon extern transport.

## Viktiga bevis

- Sessionscookie och CSRF är separata från plattformens inloggning och ger
  ingen åtkomst till kontor eller verkliga bolag. Korsursprungsanrop avvisas.
- Färska cookies kringgår inte de gemensamma korttidsgränserna. Atomisk
  reservation kontrollerar samtidighet även mellan serverinstanser.
- Sessions- och reservationskontroll fungerar efter återöppnad databas.
- Frågor, svar, rå IP-adress och API-nyckel sparas inte i användningsjournalen.
  Metadata sparas kortvarigt; se anslutningsguiden för livslängder.
- Saknad konfiguration, avbrott, nätfel, otillåtet underlag och felaktigt
  leverantörssvar ger kontrollerade fel utan hemligheter eller falska AI-svar.
- Vald kundfaktura, leverantörsfaktura, verifikation och rapportöversikt
  passerar serverns faktiska fältschema. Privatregister och bilagor ingår inte.
- Samtalet påverkar inte lokal bokföring. Byte av underlag eller demosession
  återanvänder inte gammal samtalshistorik; gamla väntande svar visas inte.
- Modellsvar visas som text. Bara serverägda källhänvisningar blir länkar.

## Gränser för resultatet

Provresultaten gäller de körda fallen. De är inte en redovisningscertifiering,
ett test av alla möjliga modellformuleringar eller ett godkännande för skarp
personuppgiftshantering. Att en nyckel är konfigurerad bevisar inte att ett
verkligt API-anrop fungerar. Ett sådant prov ska göras separat efter deploy,
utan att API-nyckeln läses ut eller loggas.

Denna etapp lägger inte till ett beständigt företagsminne, fulltextläsning av
uppladdade dokument, automatisk regeluppdatering eller en möjlighet för AI:n
att bokföra. Hela ekonomimotorns tidigare 320 tester har inte räknats som
nykörda tester i denna begränsade AI-etapp.
