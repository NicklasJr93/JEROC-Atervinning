# Integrationer – tekniska underlag

Här samlas granskningar och anslutningsunderlag inför implementation.
En dokumenterad anslutning innebär inte att integrationen är byggd eller aktiverad.

| Integration | Underlag | Status |
| --- | --- | --- |
| Naturvårdsverket – Avfallsregistret | [Öppna granskningen](naturvardsverket/README.md) | API och mockupflöden granskade; testansökan skapad; klientcertifikat och autentiserat anslutningstest återstår. |

API-nycklar, lösenord, privata nycklar och certifikatens leveransbrev förvaras
i säkra serverinställningar, separat från dokumentationen.
