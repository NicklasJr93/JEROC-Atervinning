# JEROC – kundterminal i receptionen

Fotorealistisk konceptbild, 2026-10-13.

[Öppna bilden](01_Reception_Kundgodkannande.png)

![Kontorist med egen skärm och kund som godkänner sitt viktunderlag på en separat kundterminal](01_Reception_Kundgodkannande.png)

Kontoristen arbetar på sin egen skärm. Kunden granskar sitt viktunderlag och
godkänner det på en separat pekskärm på receptionsdisken. Kontoristens skärm
behöver inte vändas mot kunden.

Personer, plats och uppgifter är fiktiva. Terminalens gränssnitt och skyltningen
är förenklade exempel för att visa användningssituationen.
